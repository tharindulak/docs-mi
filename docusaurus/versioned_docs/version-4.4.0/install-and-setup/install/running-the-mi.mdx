# Running the Micro Integrator Runtime

Follow the steps given below to run the WSO2 Micro Integrator (MI) runtime.

<Prerequisites>

## Before you begin

[Download and install](installing-mi.mdx) the Micro Integrator.

</Prerequisites>

## Starting the MI server

Follow the steps given below to start the server.

1. Open a command prompt as explained below.

      <table><tbody><tr><th>{"On "}<b>{"Linux/macOS"}</b></th><td>{"Establish an SSH connection to the server, log on to the text Linux console, or open a terminal window."}</td></tr><tr><th>{"On "}<b>{"Windows"}</b></th><td>{"Click "}<b>{"Start >Run"}</b>{", type "}<b>{"cmd"}</b>{" at the prompt, and then press "}<b>{"Enter"}</b>{"."}</td></tr></tbody></table>

2. Navigate to the `<MI_HOME>/bin` folder from your command line.
3. Execute one of the commands given below.

    -   To start the server:

        <Tabs>
        <TabItem value="tab-0" label="On macOS/Linux">

        ```bash
        sh micro-integrator.sh
        ```

        </TabItem>
        <TabItem value="tab-1" label="On Windows">

        ```bash
        micro-integrator.bat
        ```

        </TabItem>
        </Tabs>
            
    -       To start the server in background mode:

        === ""On macOS/Linux"              
            ```bash
            sh micro-integrator.sh start
            ```
        <Tabs>
        <TabItem value="tab-0" label="On Windows">

        ```bash
        micro-integrator.bat --start
        ```

        </TabItem>
        </Tabs>

## Stopping the MI server

- To stop the Micro Integrator standalone application, go to the terminal and press <i>Ctrl+C</i>.
- To stop the Micro Integrator in background mode:
      
    <Tabs>
    <TabItem value="tab-0" label="On macOS/Linux">

    ```bash
    sh micro-integrator.sh stop
    ```

    </TabItem>
    <TabItem value="tab-1" label="On Windows">

    ```bash
    micro-integrator.bat --stop
    ```

    </TabItem>
    </Tabs>
