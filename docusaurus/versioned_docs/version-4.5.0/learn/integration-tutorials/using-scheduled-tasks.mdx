# How to Periodically Execute Integration Processes

## What you'll build

The sections below demonstrate an example of a scheduled trigger (task) that injects an XML message and prints it in the server logs.

### Concepts and artifacts used

- [Sequence](../../reference/mediation-sequences.mdx)
- [Log Mediator](../../reference/mediators/log-mediator.mdx)
- [Drop Mediator](../../reference/mediators/drop-mediator.mdx)
- [Scheduled trigger](../../reference/synapse-properties/scheduled-task-properties.mdx)

## Let's get started!

<Steps>

### Set up the workspace {/* #step-1-set-up-the-workspace */}

You need Visual Studio Code (VS Code) with the <a target="_blank" href="https://marketplace.visualstudio.com/items?itemName=WSO2.micro-integrator">WSO2 Integrator: MI for VS Code</a> extension installed.

:::info

See the [Install WSO2 Integrator: MI for VS Code](../../develop/mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation to learn how to install WSO2 Integrator: MI for VS Code.

:::


### Develop the integration artifacts {/* #step-2-develop-the-integration-artifacts */}

Follow the instructions given in this section to create and configure the required artifacts.

#### Create an Integration Project

The Integration project will contain all the required artifacts for the integration solution.

1. Launch VS Code with the WSO2 Integrator: MI extension installed.

2. Click on the WSO2 Integrator: MI icon on the Activity Bar of the VS Code editor.

    <a href="https://mi.docs.wso2.com/en/4.5.0/assets/img/develop/mi-for-vscode/mi-vscode-extension.png"><img src="https://mi.docs.wso2.com/en/latest/assets/img/develop/mi-for-vscode/mi-vscode-extension.png" alt="MI VS Code Extension" width="80%" /></a>

3. Click **Create New Project** on **Design View**.

    <a href="https://mi.docs.wso2.com/en/4.5.0/assets/img/develop/mi-for-vscode/qsg/design-view-pane-create-new-project.png"><img src="https://mi.docs.wso2.com/en/latest/assets/img/develop/mi-for-vscode/qsg/design-view-pane-create-new-project.png" alt="Design View Pane Create New Project" width="80%" /></a>

    Next, the **Project Creation Form** will be opened.


4. In the **Project Creation Form**, enter `ScheduleTaskTutorial` as the **Project Name**.

5. Provide a location under **Select Project Directory**.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/create-new-project.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/create-new-project.png" alt="create new project" width="80%" /></a>

6. Click **Create**.

Now let's start designing the integration by adding the necessary artifacts.

#### Create a Scheduled trigger (task)

1. In the **Add Artifact** interface, under **Create an Integration**, click on **Automation**. This opens the Automation Form.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/automation-artifact.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/automation-artifact.png" alt="create automation artifact" width="80%" /></a>

    :::note

    WSO2 Integrator: MI supports automation flows that can be triggered either on a schedule or at server startup. It provides two types of automations:

    - **Scheduled Triggers (Task)** – Executes a task repeatedly based on a defined interval or cron expression. (You will explore this in this tutorial.)

    - **Startup Triggers** – Executes a task once when the WSO2 Integrator: MI starts, runs the integration, and then shuts down. To learn more, refer to [Running the WSO2 Integrator: MI in Automation Mode](../../install-and-setup/install/running-the-mi-in-automation-mode.mdx).

    :::

2. Enter the details given below to create a new REST API.

3. Click **Create**. This will open the integration flow (sequence) that will be executed by the configured Scheduled Trigger.

#### Update the mediation flow

You can now start designing the integration logic. We will add a [Log Mediator](../../reference/mediators/log-mediator.mdx) to log the message when the Scheduled Trigger executes the flow.

1. Click on the **+** icon on the canvas to open the **Mediator Palette**.

2. Under **Mediators**, select the **Log** mediator.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/select_log_mediator.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/select_log_mediator.png" alt="create new task" width="80%" /></a>

3. Provide `City = ${xpath("//city")}` as the **Message**, and click **Add** to insert the **Log** mediator into the integration flow.

4. Click on the **+** icon after the **Log** mediator to open the **Mediator Palette**. We will add a [Drop Mediator](../../reference/mediators/drop-mediator.mdx) to stop processing the current message after it is logged.

5. Under **Mediators**, select the **Drop** mediator, and click **Add** to insert it into the integration flow.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/select_drop_mediator.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/select_drop_mediator.png" alt="create new task" width="80%" /></a>

You have successfully completed the integration flow with the scheduled trigger and logged the message. For reference, you can review the configured scheduled trigger (task) and the sequence.

### Build and run the artifacts {/* #step-3-build-and-run-the-artifacts */}

Now that you have developed an integration using the WSO2 Integrator: MI for the Visual Studio Code plugin, it's time to deploy the integration to the WSO2 Integrator: MI server runtime.

Click the **Build and Run** icon located in the top right corner of VS Code.

<a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/build_and_run_btn.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/build_and_run_btn.png" alt="Build and Run" width="80%" /></a>

### Test the use case {/* #step-4-test-the-use-case */}

When you run the integration artifact as described in [Step 3](#step-3-build-and-run-the-artifacts), you will see the injected XML message being printed in the WSO2 Integrator: MI logs every 5 seconds, in the **Output** tab of VS Code.

<a href="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/output_log.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/using-scheduled-tasks/output_log.png" alt="MI output logs" width="80%" /></a>

</Steps>
