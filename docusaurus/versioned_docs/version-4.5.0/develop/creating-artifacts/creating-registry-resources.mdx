# Create a Resource

Follow these steps to create a new resource artifact in MI for VS Code.

1. Launch Visual Studio Code with the WSO2 Integrator: MI for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install WSO2 Integrator: MI for VS Code](../mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation for a complete installation guide.

    :::

2. Create an [integration project](../create-integration-project.mdx).


3. To add a new Resource, navigate to **WSO2 Integrator: MI Project Explorer**.

4. Click on the **+** icon to open the **Add Artifact** pane.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/add-artifact-icon.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/add-artifact-icon.png" alt="add artifact" width="40%" /></a>

5. Click **+ View More** under **Create an Integration**.

6. Click **Resource** under **Other Artifacts** to open the **Resource Creation Form**.

    This will open the **New Resource** window.

    <img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_resource/resource-create-form.png" width="800" />

7. Select one of the following options:

    - [From existing template](#from-existing-template)
    - [Import from file system](#import-from-file-system)

    ### From existing template

    Use the **From existing template** option if you want to generate a resource from a template.
    
    <img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_resource/resource-from-existing-template.png" width="800" />
    
    Select a resource template for the **Template Type** field. Then enter a unique name for the **Resource Name**. In this example, a **XSLT File** template is used.
    
    ### Import from file system
    
    Use the **Import from file system** option to import a file.
    
    <img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_resource/resource-importing.png" width="800" />
    
    Use **Browse file** to find the relevant file.

8. Under **Resource Path**, specify the location to save the resource.

    <img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_resource/resource-save.png" width="800" />   
   
9. Once you specify the necessary properties, click **Create**.
