# Create a Message Processor

Follow the instructions below to create a new [Message Processor](../../reference/synapse-properties/about-message-stores-processors.mdx) artifact in the WSO2 Integrator: MI for Visual Studio Code extension (MI for VS Code).

## Instructions

### Create the message processor artifact

1. Launch Visual Studio Code with the WSO2 Integrator: MI for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install WSO2 Integrator: MI for VS Code](../mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation for a complete installation guide.

    :::

2. Create an [integration project](../create-integration-project.mdx).


3. To add a new Message Processor, navigate to **WSO2 Integrator: MI Project Explorer**.

4. Click on the **+** icon to open the **Add Artifact** pane.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/add-artifact-icon.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/add-artifact-icon.png" alt="add artifact" width="40%" /></a>

5. Click **+ View More** under **Create an Integration**.

6. Click **Message Processor** under **Other Artifacts** to open the **Message Store Form**.

7. Select the type of message processor you are creating.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/message-processor-form.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/message-processor-form.png" alt="message processor form" width="80%" /></a>

8. Enter a unique name for the message processor.

    See the links given below for descriptions of properties for each message processor type:

    -	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
    -	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
    -	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)

9. Click **Create**.

The message processor is created in the `<PROJECT_NAME>/src/main/wso2mi/artifacts/message-processors` folder under the integration project you created.

### Update the properties

Open the above-created message processor artifact from the **MI Project Explorer**. You can use the **Form** view or the **Source** view to update message processor properties.

See the links given below for descriptions of properties for each processor type:

-	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
-	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
-	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)
