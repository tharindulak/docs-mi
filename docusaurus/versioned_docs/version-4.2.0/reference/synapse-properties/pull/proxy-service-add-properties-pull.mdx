To add service-level transport parameters to a proxy service:

1.  Open your proxy service artifact in **WSO2 Integration Studio**.
2.  In the **Design View**, go to the **Properties** tab and expand the **Parameters** section as shown below.

    <img src="/integration/micro-integrator/_versions/4.2.0/assets/img/integrate/create_artifacts/new_proxy_service/service-level-params.png" width="700" />

2.  Click the **plus** <img src="/integration/micro-integrator/assets/img/integrate/common/plus-icon.jpg" width="20" /> icon to open the following dialog box and add the parameter name and value as a key-value pair:

    <img src="/integration/micro-integrator/_versions/4.2.0/assets/img/integrate/create_artifacts/new_proxy_service/service-level-params-dialog.png" width="500" />
