# Creating a Message Processor

Follow the instructions given below to create a new [Message Processor](../../reference/synapse-properties/about-message-stores-processors.mdx) artifact in WSO2 Integration Studio.

## Instructions

### Creating the Message Processor artifact

1.  Right-click the [ESB Config project](../create-integration-project.mdx#esb-config-project) and go to **New → Message Processor** to open the **New Message Processor Artifact** dialog box.

	<img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_message_processor/select-message-processor.jpg" />

2.  Select **Create a new message-processor artifact** and click **Next**.

	<img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_message_processor/new-message-processor-wizard-1.png" width="500" />

3.  Enter a unique name for this message processor, specify the type of processor you're creating.

	<img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_message_processor/new-message-processor-wizard-2.png" width="500" />

	See the links given below for descriptions of properties for each message processor type:

	-	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
	-	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
	-	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)

4.  Do one of the following to save the artifact:

  	-   To save the message processor in an existing ESB Config project in your workspace, click **Browse** and select that project.
  	-   To save the message processor in a new ESB Config project, click **Create new Project** and create the new project.

5.  Click **Finish**. 

The message processor is created in the `src/main/synapse-config/message-processors` folder under the ESB Config project you specified.

### Updating the properties

Open the new message processor artifact from the project explorer. You can use the **Form** view or the **Source** view to update message processor properties.

<img src="/integration/micro-integrator/assets/img/integrate/create_artifacts/new_message_processor/message-processor-form-view.png" width="800" />

See the links given below for descriptions of properties for each processor type:

-	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
-	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
-	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)
