# Create a Message Processor

Follow the instructions below to create a new [Message Processor](../../reference/synapse-properties/about-message-stores-processors.mdx) artifact in the Micro Integrator for Visual Studio Code extension (MI for VS Code).

## Instructions

### Create the message processor artifact

1. Launch Visual Studio Code with the Micro Integrator for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install Micro Integrator for VS Code](../mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation for a complete installation guide.

    :::

2. Create an [integration project](../create-integration-project.mdx).


2. Go to **Micro Integrator Project Explorer** > **Message Processors**.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/create-message-processor.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/create-message-processor.png" alt="Create message processor" width="30%" /></a>

3. Hover over **Message Processors** and click the **+** icon that appears to open the **Message Processor Form** below.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/add-message-processor.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/add-message-processor.png" alt="Add message processor" width="30%" /></a>

4. Select the type of message processor you are creating.

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-message-processor/message-processor-form.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-message-processor/message-processor-form.png" alt="message processor form" width="80%" /></a>

5. Enter a unique name for the message processor.

	See the links given below for descriptions of properties for each message processor type:

	-	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
	-	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
	-	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/new-message-processor.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-message-processor/new-message-processor.png" alt="new message processor" width="80%" /></a>

6. Click **Create**.

The message processor is created in the `src/main/wso2mi/artifacts/message-processors` folder under the integration project you created.

### Update the properties

Open the above-created message processor artifact from the **MI Project Explorer**. You can use the **Form** view or the **Source** view to update message processor properties.

See the links given below for descriptions of properties for each processor type:

-	[Message Sampling Processor properties](../../reference/synapse-properties/message-processors/msg-sampling-processor-properties.mdx)
-	[Scheduled Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-forwarding-processor-properties.mdx)
-	[Scheduled Failover Message Forwarding Processor properties](../../reference/synapse-properties/message-processors/msg-sched-failover-forwarding-processor-properties.mdx)
