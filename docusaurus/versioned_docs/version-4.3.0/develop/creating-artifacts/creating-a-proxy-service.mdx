# Create a Proxy Service

Follow these instructions to create a [Proxy Service](../../reference/synapse-properties/proxy-service-properties.mdx) artifact in the Micro Integrator for Visual Studio Code extension (MI for VS Code).

## Create a new proxy service artifact

1. Launch Visual Studio Code with the Micro Integrator for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install Micro Integrator for VS Code](../mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation for a complete installation guide.

    :::

2. Create an [integration project](../create-integration-project.mdx).


    Hereafter, this project will be referred to as `<PROJECT_NAME>`.

3. Go to **MI Project Explorer** > **Proxy Services**.

4. Hover over **Proxy Services** and click the **+** icon that appears to open the **Proxy Service Form** below.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/proxy-service.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/proxy-service.png" alt="proxy service" width="80%" /></a>

5. Enter a unique name for the proxy service.

6. Once you complete the **Proxy Service Form**, click **Create**.

:::info

You can switch to the default Visual Studio Code **Explorer** to view the folder structure.

The newly-created proxy service will be stored in the `<PROJECT_NAME>/src/main/wso2mi/artifacts/proxy-services` folder of your integration project.

:::

## Design the integration

1. Go to the **MI Overview** interface.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/mi-overview.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/mi-overview.png" alt="MI overview" width="80%" /></a>

2. Click on the proxy service you created to go to its **Resource View**.

    The default **Resource View** will be as follows:
   
    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-proxy-service/proxy-service-design-view.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-proxy-service/proxy-service-design-view.png" alt="source view" width="80%" /></a>

3. Add the required mediators and connectors and design the integration flow.

## Update the configurations

1. Go to **MI Overview**.

2. Under **Proxy Services**, select the proxy service you want to edit to go to its **Resource View**.

3. Click the **Edit** icon to edit the proxy service.

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-proxy-service/edit-proxy-service.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-proxy-service/edit-proxy-service.png" alt="Edit proxy service" width="80%" /></a>

4. Add the required parameters.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/edit-proxy-view.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-proxy-service/edit-proxy-view.png" alt="Edit proxy view" width="80%" /></a>

5. Click **Update**.

   See the following links for the list of transport parameters you can use:

   - [VFS Parameters](../../reference/synapse-properties/transport-parameters/vfs-transport-parameters.mdx)
   - [JMS Parameters](../../reference/synapse-properties/transport-parameters/jms-transport-parameters.mdx)
   - [FIX Parameters](../../reference/synapse-properties/transport-parameters/fix-transport-parameters.mdx)
   - [MailTo Parameters](../../reference/synapse-properties/transport-parameters/mailto-transport-parameters.mdx)
   - [MQTT Parameters](../../reference/synapse-properties/transport-parameters/mqtt-transport-parameters.mdx)
   - [RabbitMQ Parameters](../../reference/synapse-properties/transport-parameters/rabbitmq-transport-parameters.mdx)

   See the complete list of [service-level properties and parameters](../../reference/synapse-properties/proxy-service-properties.mdx) that you can configure.

You can update the proxy service using this view.
