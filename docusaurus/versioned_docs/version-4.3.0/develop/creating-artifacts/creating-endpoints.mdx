# Create an Endpoint

Follow the instructions below to create a new [Endpoint](../../reference/synapse-properties/endpoint-properties.mdx) artifact in the Micro Integrator for Visual Studio Code extension (MI for VS Code).

## Instructions

### Create the endpoint artifact

1. Launch Visual Studio Code with the Micro Integrator for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install Micro Integrator for VS Code](../mi-for-vscode/install-wso2-mi-for-vscode.mdx) documentation for a complete installation guide.

    :::

2. Create an [integration project](../create-integration-project.mdx).


3. Go to **MI Project Explorer** > **Endpoints**.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-endpoint/create-new-endpoint.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-endpoint/create-new-endpoint.png" alt="Create endpoint" width="30%" /></a>

4. Hover over **Endpoints** and click the **+** icon that appears to open the **Endpoint Form** below.

    <a href="/integration/micro-integrator/assets/img/learn/tutorials/add-endpoint.png"><img src="/integration/micro-integrator/assets/img/learn/tutorials/add-endpoint.png" alt="Add endpoint" width="30%" /></a>

5. Select the endpoint type you want from the **Endpoint Form**.

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/endpoint-form.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/endpoint-form.png" alt="Endpoint form" width="80%" /></a>

6. Enter a unique name for the endpoint.

7. Specify values for the [required parameters](../../reference/synapse-properties/endpoint-properties.mdx) for the selected endpoint type.

8. Click **Create** to save the endpoint configuration.

The endpoint will be created in the `<PROJECT_NAME>/src/main/wso2mi/artifacts/endpoints` folder under the integration project you created.

### Design the integration

:::note

Endpoints cannot be added directly to the integration sequence. Instead, they must be invoked using the [Send Mediator](../../reference/mediators/send-mediator.mdx) or the [Call Mediator](../../reference/mediators/call-mediator.mdx).

Therefore, to add an endpoint artifact to the integration sequence, use the Send Mediator or the Call Mediator.

:::

1.	Open the **Design View** of your [mediation sequence](../../reference/mediation-sequences.mdx).
2.  Add the **Call Endpoint** mediator from the palette under **All Mediators** > **Generic** section to the relevant position in the mediation sequence:

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/select-call-endpoint.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/select-call-endpoint.png" alt="Select call endpoint" width="30%" /></a>

    :::tip

    Similarly, you can use the Send Mediator instead of the Call Mediator.

    :::

3. In the **Call Endpoint** form, select the endpoint you need to invoke under **Select Endpoint**. You can also select **Create New** to create a new endpoint artifact.

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/call-endpoint.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/call-endpoint.png" alt="Call endpoint" width="30%" /></a>

The endpoint artifact is now linked to your integration sequence.

### Update the properties

1. Go to **MI Project Explorer**.

2. Select the endpoint artifact available under `<PROJECT_NAME>/Endpoints/`. 

You can use the **Form** view or the **Source** view to update endpoint properties.

#### To update from the Form View:

1. Go to **MI Overview**.
2. Under the **Endpoints** available, select the endpoint that you need to update the properties. The **Endpoint Form** will be opened.
3. Update the properties.
4. Click **Save Changes**.

#### To update from the Source View:

1. Go to **MI Overview**.
2. Under the **Endpoints** available, select the endpoint you want.
3. Click on the **Show Source** (**<b>&lt;/&gt;</b>**) icon located in the top right corner of the VS Code. 

    <a href="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/show-source.png"><img src="/integration/micro-integrator/_versions/4.3.0/assets/img/develop/create-artifacts/create-endpoint/show-source.png" alt="Show source" width="50%" /></a>

    This will open the source view of the endpoint artifact.

    <a href="/integration/micro-integrator/assets/img/develop/create-artifacts/create-endpoint/endpoint-source-view.png"><img src="/integration/micro-integrator/assets/img/develop/create-artifacts/create-endpoint/endpoint-source-view.png" alt="Endpoint source view" width="50%" /></a>

To learn more about all available endpoint properties, see the [endpoint properties](../../reference/synapse-properties/endpoint-properties.mdx) documentation.
