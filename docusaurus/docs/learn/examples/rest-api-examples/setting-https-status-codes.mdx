# How to Handle HTTP Status Codes
A REST service typically sends HTTP status codes with its response. When you configure an API that send messages to a SOAP back-end service, you can set the status code of the HTTP response within the configuration. To achieve this, set the status code parameter within the API resource definition.

## Synapse configuration  

Following is a sample REST API configuration that we can used to implement this scenario. See the instructions on how to [build and run](#build-and-run) this example.

<Tabs>
<TabItem value="tab-0" label="REST API">

 ```xml
 <api xmlns="http://ws.apache.org/ns/synapse" name="StockQuoteAPI" context="/stockquote">`
     <resource uri-template="/view/{symbol}" methods="GET">
         <inSequence>
             <payloadFactory media-type="xml">
                 <format>
                     <m0:getQuote xmlns:m0="http://services.samples">
                         <m0:request>
                         <m0:symbol>$1</m0:symbol>
                         </m0:request>
                     </m0:getQuote>
                 </format>
                 <args>
                     <arg expression="get-property('uri.var.symbol')"/>
                 </args>
             </payloadFactory>
             <header name="Action" value="urn:getQuote"/>
             <call>
                 <endpoint key="SimpleStockQuoteService" />
             </call>
             <property name="HTTP_SC" value="201" scope="axis2" />
             <respond />
         </inSequence>
     </resource>
 </api>
 ```

</TabItem>
<TabItem value="tab-1" label="Endpoint">

 ```xml
 <endpoint name="SimpleStockQuoteService" xmlns="http://ws.apache.org/ns/synapse">
     <address uri="http://localhost:9000/services/SimpleStockQuoteService"/>
 </endpoint>
 ```

</TabItem>
</Tabs>

## Build and run

Create the artifacts:

1. Launch Visual Studio Code with the WSO2 Integrator: MI for VS Code extension (MI for VS Code) installed.

    :::info

    Follow the [Install WSO2 Integrator: MI for VS Code](../../../../develop/mi-for-vscode/install-wso2-mi-for-vscode) documentation for a complete installation guide.

    :::

2. Create an [integration project](../../../../develop/create-integration-project/).

3. [Create the rest API](../../../develop/creating-artifacts/creating-an-api.mdx) with the configurations given above.
4. [Deploy the artifacts](../../../develop/deploy-artifacts.mdx) in your WSO2 Integrator: MI.

Set up the back-end service:

1. Download the [back-end service](https://github.com/wso2-docs/WSO2_EI/blob/master/Back-End-Service/axis2Server.zip).
2. Extract the downloaded zip file.
3. Open a terminal, navigate to the `axis2Server/bin/` directory inside the extracted folder.
4. Execute the following command to start the axis2server with the SimpleStockQuote back-end service:
 
    <Tabs>
    <TabItem value="tab-0" label="On MacOS/Linux">

      ```bash
      sh axis2server.sh
      ```

    </TabItem>
    <TabItem value="tab-1" label="On Windows">

      ```bash
      axis2server.bat
      ```

    </TabItem>
    </Tabs>

Send the following request to the WSO2 Integrator: MI:
    
```bash
curl -v http://127.0.0.1:8290/stockquote/view/IBM
```

The response message will contain the following response code (201) and the requested stock quote information.  

```bash

< server: ballerina
< Access-Control-Allow-Methods: GET
< content-type: text/plain
< Access-Control-Allow-Headers: 
< Date: Tue, 29 Oct 2019 15:41:05 GMT
< Transfer-Encoding: chunked
```
